# AULA 07 - Trabalho Prático: Decisões Arquiteturais em Casos Reais

Baseada no livro *Fundamentals of Software Architecture: An Engineering Approach* (Mark Richards & Neal Ford).

Trabalho em duplas que aplica o conteúdo da [AULA 06 - Estilos Arquiteturais](../AULA%2006%20-%20estilos-arquiteturais/README.md) a três decisões reais de arquitetura: **Prime Video** (juntou), **Shopify** (organizou sem separar) e **Netflix** (separou).
